# Credits

## Design and artwork

- OTHER/FORM name, identity, layout, interface, copy, and case-study presentation were created for this project.
- All four project artworks are original procedural SVG compositions generated in source code.
- The hero sculpture and particle fields are generated from geometry and code; no external models or textures are used.
- `https://basement.studio/` was studied as a quality and interaction reference only. No source code, imagery, logos, fonts, or other assets were copied.

- **Archivo Variable** — Omnibus-Type, SIL Open Font License 1.1.

Font license files are included in the corresponding `node_modules/@fontsource*` packages during installation.
